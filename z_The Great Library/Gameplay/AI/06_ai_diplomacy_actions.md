# 06. ИИ-дипломатия: FUN_00820DF0

Адреса VA. Основной декомпил - decomp/v2game/FUN_00820df0_00820df0.c.

## Контекст

FUN_00820DF0 - часть дневного AI-диспетчера FUN_0081E9E0. Она обрабатывает country+0x0CE4 - список отложенных дипломатических кандидатов/действий.

Для каждого объекта:

1. FUN_00911760 проверяет базовую допустимость.
2. Виртуальный метод объекта+0x6C проверяет, что действие ещё применимо.
3. Требуется object+0x24 == 1.
4. По типу object+0x24 поля типа? фактически ID лежит в vtable/объекте+0x20 и читается как action type.
5. Специализированный scorer возвращает шанс 0..100.
6. Score < 50 - отказ.
7. Score >= 50: Random()%100 сравнивается со score.
8. Успех переводит объект в state 3 и отправляет команду; отказ переводит в state 2.

Если объект принадлежит другой стране, многие типы получают автоматический шанс 100.

## FUN_0083DE70 - война/CB

Сильная функция, около 500 строк.

Основные данные:

| Объект | Поле |
|---|---|
| country+0x0BE8 | relation matrix |
| relation+0x34 | war flag |
| relation+0x3C | opinion/attitude |
| object+0x34..0x44 | side/country списки |
| object+0x54..0x68 | war goals |
| object+0x74..0x88 | support lists |
| object+0x98..0xEC | modifiers |
| country+0x0DA8..0x0DAC | selected target list |

Функция:

1. Проверяет, что relation+0x34 != 0.
2. FUN_00936FC0 вычисляет взаимную позицию self/target.
3. Считает силы, союзников и количество настоящих целей.
4. Обрабатывает CWarGoal, включая special check goal id 0x08A1.
5. Применяет modifiers через FUN_005DCBD0.
6. Считает military strength и date/war-duration factors.
7. Штрафует за отсутствие поддержки, союзников и цели.
8. При выполнении условий возвращает 100; иначе 0.

Внутри используются константы 200, 500, 1000, 10000 и пороги продолжительности войны из define DAT_012586DC+0x60.

## FUN_00841640

Простая обёртка. Выбирает target country index из object+0x0C/+0x14 и вызывает FUN_0083EC10. Результат используется как оценка отношений.

## FUN_008419C0

Большая функция около 600 строк.

Она проверяет:

| Поле | Роль |
|---:|---|
| target country+0x0430 | уже есть отношение/соглашение |
| country+0x0D58..0x0D5C | список блокирующих стран |
| country+0x03DC | +50 за совпадение |
| country+0x03A4 | +25 за совпадение |
| country+0x03F8 | -50 за совпадение |
| country+0x0DA8..0x0DAC | +200 за выбранную цель |

Если блокирующая запись найдена, функция возвращает -1000. При параметре подробности она также формирует tooltip/log.

## FUN_00842A00

Очень простая:

    для цивилизованной country, если target уже находится в country+0x04A4:
        return 100
    иначе return 0

## FUN_00842A50 - military access

Работает с CAskMilitaryAccessAction.

Ветки:

1. Если у target уже есть доступ к sender, score = 1000.
2. Если action уже находится в target country+0x04A4, score = -1000.
3. Иначе создаётся объект CAskMilitaryAccessAction и вызывается FUN_0083DB20.
4. Дополнительная война-ветка проверяет country+0x0DA8..0x0DAC и вызывает FUN_00832280.

## FUN_008430D0

Явно создаёт CAskMilitaryAccessAction, вызывает FUN_008419C0 и возвращает:

    score = 50 - FUN_008419C0

## FUN_008416B0

Проверяет CB-скан FUN_0092EDE0 и текущую страну+0x156C. Если доступно или уже выполняется проект, считает количество совпадающих провинций country+0x09F8.

Правила:

    >2 совпадений -> 100
    иначе score = 50 - relation score из FUN_0083EC10

## FUN_00841900

Вызывает FUN_00834150, добавляет случайную компоненту 500. Для локальной/особой страны дополнительно обходит список world+0x0B3C через FUN_00832DD0 и суммирует бонус.

## FUN_00844050 и FUN_00844140

Обе функции читают object+0x10/+0x14, FUN_00834150 и хэш country+0x03B8..0x3BC.

FUN_00844050:

    если порог < 0x33, score = 0
    иначе score = (200 - relation+0x3C/1000) / 2
    если обе страны civil/flag, score делится на 2

FUN_00844140:

    зеркальное условие
    score = (relation+0x3C/1000 + 200) / 2

## FUN_00843A10 - sphere comparison

Проверяет world+0x0CF8+8, FUN_00838EB0 и списки великих держав. Если порядок/позиция устраивает:

    return 100
иначе 0.

## FUN_00843B90

Функция использует:

| Поле | Роль |
|---:|---|
| target country+0x0080 | таймер |
| country+0x0D08 | флаг цели |
| country+0x0BE4 | capital/province |
| state+0x16C | sphere/world object |
| country+0x09D8 | провинции |
| building index DAT_01258720 | военные здания |

Она суммирует расстояния/доступность через FUN_004FB7D0, добавляет бонусы 40 и 20, затем Random()%100 сравнивается с шансом.

## FUN_00843170 - большая война/мир оценка

Функция работает с world+0x0CF8+8 (active war/crisis object).

Она проверяет стороны war+0x18 и war+0x20, собирает списки участников, применяет modifiers FUN_005DCBD0 и считает:

1. Количество провинций/целей.
2. Военную силу.
3. War score и расстояние от 50000/1200000.
4. Занятость страны.
5. Отношение сторон.
6. Штрафы и бонусы по числу участников.
7. Клампы результата и Random comparison.

Возвращается 100 или 0.
