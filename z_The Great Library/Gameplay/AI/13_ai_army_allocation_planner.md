# 13. Army allocation planner: FUN_00851BD0

Адреса VA. Основной декомпил - FUN_00851bd0_00851bd0.c. Это балансировщик активных военных задач: он решает, какие армии остаются на текущей цели, какие перебрасываются, а где нужно создать новое соединение.

## Вход

    FUN_00851BD0(AI object)

Основные поля:

| Объект | Смещение | Значение |
|---|---:|---|
| country | +0x0A10 | порог включения сложного планировщика |
| AI object | +0x85 | список активных военных задач |
| AI object | +0x77/+0x79 | другой список задач |
| AI object | +0x87 | счётчик этапа |
| AI object | +0xE | индекс страны |
| задача | +0x37 | страна-цель |
| задача | +0x3A | занятость/обработана |
| задача | +0x24 | цель/провинция |
| задача | +0x2B | армия/объект |
| задача | +0x2D | минимум соединений |
| задача | +0x1BD | флаг неудачи |

Если country+0x0A10 > 1, запускается расширенный режим.

## Фаза 1. Распределение существующих армий

Для каждой активной задачи A:

1. targetCountry = country[task+0x37].
2. local_28 = targetCountry+0x0E8 - список текущих врагов/целей.
3. FUN_0048F070(enemy,1) проверяет, что война/цель активна.
4. Virtual задача+0x1A4 возвращает список армий, назначенных этой задаче.

Для каждой армии B:

1. Проверяется army+0x37 - страна-цель.
2. targetCountry+0x0E8 не должен совпадать с текущим списком A.
3. Армия и target не должны уже быть в обработанных списках.
4. Для каждой другой задачи B:
   - берётся её список армий;
   - проверяется army+0x0DC и country+0x0E8;
   - если армия противоположной стороны или FUN_004E0AC0 подтверждает совпадение, армия может быть передана.

Если нужно передать армию:

    FUN_0082E190(...) вызывается дважды
    бюджет задачи уменьшается на army+0x98
    армия добавляется в выбранный список

Если бюджет остался, функция ищет другие задачи с тем же противником и уменьшает их требование по формуле:

    supported = (country+0x09C+8) * 2 / 1000
    capacity = supported * (market+0x2C + 1000) / 1000
    need = capacity / 3000 - existingArmies

Если после фазы остались выбранные армии, вызывается FUN_009A63F0 и функция возвращается.

## Фаза 2. Оценка нехватки войск

Для каждой активной задачи:

1. targetCountry = country[task+0x37].
2. Считается количество армий по сторонам из task+0x24.
3. Базовый штраф локально равен 500000.0.
4. Для каждой другой активной задачи:
   - virtual задача+0x1A4 возвращает её армии;
   - суммируются армии, прошедшие virtual +0x38;
   - читается country+0x128;
   - читается market+0x2C;
   - manpower = (country+0x9C+8) * 2 / 1000;
   - capacity = manpower * (market+0x2C + 1000) / 1000;
   - если armies*3 < capacity/1000, считается нехватка.
5. Выбирается цель с минимальным score.

Формула score:

    если нет выбранного направления:
        score = distance * 10 / 1000 + 10
    иначе, если новое направление не в общем списке:
        снова distance score
    иначе:
        relationScore = FUN_004A0E80 / 1000 * 0.0001
        score = 0.05 * armyCount
        score += количество врагов из списков армии
        score += число сторон A и B, если они активны

Если score < local_40, цель становится лучшей.

Если лучшая цель найдена, создаётся список с владельцем цели и вызывается FUN_0082DC50 - создание/передача армии. После этого цикл продолжается по оставшимся задачам.

Если кандидата нет, AI object+0x1BD = 1.

## Фаза 3. Сбор уникальных направлений

Если country+0x0A10 <= 1, функция строит список уникальных стран из активных задач:

| Условие |
|---|
| задача+0x0B4 > 0 |
| world+0x0ACC + 0xDC != 0 |
| country+0x0E8 != 0 |

FUN_0048F070(country,1) проверяет активность войны. Только уникальные страны добавляются в список.

## Фаза 4. Подкрепление слабых задач

Требуется AI object+0x87 >= 2.

Для каждой задачи с task+0x2D >= 1:

1. task+0x2B - армия/точка.
2. Определяется провинция:
   - если army+0x0A0 != 0, берётся province из world+0x0ACC;
   - иначе берётся army+0x0DC.
3. Проверяется, что province+0x58 == task+0x37.
4. Считается требуемый контингент:

       population = provinceOwner+0x128
       marketCapacity = market+0x2C
       manpower = country+0x9C+8 + 1000
       capacity = manpower * 2 / 1000 * (marketCapacity + 1000) / 1000
       existing = сумма army+0x98 в task army list
       need = existing*3 - capacity/1000
       need = need / 3

5. Если need > 0, другие задачи отправляют недостающее:
   - для каждой другой задачи считается её свободная ёмкость по той же формуле;
   - virtual задача+0x1A4 вызывается с количеством;
   - FUN_0082DC50 передаёт armies;
   - FUN_00828F90 уменьшает армию-источник;
   - virtual AI object+0x1A8 добавляет армию к текущей задаче.

## MP-детали

Функция использует Random только опосредованно через создаваемые команды и базовые командные ID:

    DAT_0131CA68 = FUN_009C12D0()
    DAT_01258A9C += 1

Сама математика баланса детерминирована. Ошибки в составе списков задач или армий изменят число команд и приведут к рассинхрону.
