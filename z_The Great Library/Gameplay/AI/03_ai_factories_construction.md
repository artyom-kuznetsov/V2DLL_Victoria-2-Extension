# 03. ИИ: фабрики и строительство

Адреса VA. Сырые декомпилы - в decomp/v2game.

## Планировщик FUN_004A5170

Вход: AI command/state. Функция читает:

| Поле | Значение |
|---|---|
| command+0x6C | state/building context |
| state+0x058 | state object |
| state+0x05C | country index |
| state+0x060 | цепочка фабрик |
| country+0x0B00 | разрешить фабрики |
| country+0x0B08 | разрешить один класс действий |
| country+0x0B10 | разрешить закрытие/перепрофиль |

Сначала считаются три счётчика по цепочке фабрик:

1. closed/unprofitable:
   country+0x0B10 включён и фабрика+0x184 > 10 или +0x188 != 0;
2. капиталисты могут строить: FUN_004A75B0;
3. базовый лимит state+0x068 + 1.

Затем выбирается один из четырёх обработчиков:

| Индекс | Функция | Действие |
|---:|---|---|
| 0 | FUN_004A5420 | построить/расширить фабрику |
| 1 | FUN_004A5E00 | infra/province project |
| 2 | FUN_004A60B0 | вторая infra/военная постройка |
| 3 | FUN_004A5C40 | закрыть/перепрофилировать фабрику |

Если country+0x0B00 = 0, вес варианта 0 обнуляется. Если +0x0B10 = 0, обнуляется высокий DWORD счетчика закрытий. Если +0x0B08 = 0, обнуляется младший DWORD.

Мод FACTORY_AI_SPAM_FIX меняет VA 0x00857614 внутри FUN_00857530 и разрешает расширение только при занятости >= ai_factory_expand_min_staffing.

## FUN_004A5420 - новая/расширенная фабрика

Файл: FUN_004a5420_004a5420.c.

Функция:

1. Создаёт временные объекты команд.
2. Проходит регионы и фабрики.
3. FUN_0052CA30 проверяет, можно ли строить тип в регионе.
4. Считает score по населению, ресурсам, деньгам и случайному числу.
5. Выбирает лучшую фабрику/регион.
6. Создаёт construction command.

Эта функция использует Random()%100 и fixed-point расчёты.

## FUN_004A5E00 - province project

Файл: FUN_004a5e00_004a5e00.c.

Функция:

1. FUN_0047E3E0 читает набор товара/ресурса.
2. FUN_009DCAC0 - строительный контекст.
3. FUN_0048C050 - проверка/создание проекта.
4. Случайный выбор через FUN_009B7950.

## FUN_004A60B0 - вторая infra/военная постройка

Файл: FUN_004a60b0_004a60b0.c.

Похожа на FUN_004A5E00, но сначала вызывает FUN_004A75B0 для капиталистов и выбирает между провинциальными проектами через FUN_0048C050.

## FUN_004A5C40 - закрытие/перепрофилирование

Файл: FUN_004a5c40_004a5c40.c.

1. FUN_004A4550 - candidate calculator.
2. FUN_004DADA0/FUN_004DC340 - создают команду закрытия/перепрофилирования.
3. Random выбирает среди кандидатов.

## FUN_0081F3B0 - управление существующими фабриками

Функция активна при country+0x0AF8 != 0.

Алгоритм:

1. FUN_0052B510 считает фактический доход страны.
2. Из него вычитаются пять expense-категорий и ещё одна статья +0x50.
3. Если остаток выше глобального лимита DAT_013F3688/8C, функции exit; AI не тратит лишнее на поддержку.
4. Иначе проходит регионы и цепочки фабрик.
5. Для каждой фабрики рассматриваются:
   - level > 0;
   - stop counter +0x184 < 11;
   - не закрыта +0x188 = 0;
   - loss days +0x178;
   - субсидия +0x180;
   - деньги/закупки +0x150..+0x17C.
6. Random выбирает кандидат.
7. FUN_005827F0 создаёт команду субсидии/закрытия/перезапуска.

Если лимит не позволяет содержание, функция собирает отдельный список фабрик и FUN_00821640 сортирует кандидатов на отключение.

## FUN_0081FB00 - строительство новых фабрик

Функция использует:

| Поле | Значение |
|---:|---|
| country+0x0EC4 | рыночный спрос/стоимость |
| country+0x1560 | множитель бюджета |
| country+0x0A60+0x48 | административный множитель |
| country+0x0E70 | tax efficiency |
| province+0x4C | количество провинций |
| province+0x50 | население/рабочая сила |
| province+0x0D8 | construction queue |

Логика:

1. Оценивает доступный бюджет из дохода и define.
2. Идёт по регионам и считает количество уже строящихся фабрик.
3. Сравнивает бюджет с текущими затратами.
4. Если проектов мало, рассматривает новые фабрики.
5. Классифицирует товары по четырём группам FUN_005DC0A0.
6. Сравнивает доли групп с define DAT_012586DC+0x20+0xA8/0xAC/0xB0.
7. FUN_005F2AE0 создаёт команду постройки выбранной фабрики.
8. Если бюджет исчерпан, вызывает FUN_009A63F0.

## FUN_00820760 - провинциальные здания

Функция активна при определённом количестве свободных слотов и country+0x067C == 0.

1. FUN_0051F8C0 очищает контекст.
2. Считает стоимость существующих проектов province+0x0D8.
3. Сравнивает её с define DAT_012586DC+0x20+0xBC.
4. Если лимит превышен, возможно FUN_0081E040 - отмена/перераспределение.
5. Иначе собирает доступные типы зданий из рынка market+0x310 и фильтрует по country+0x150.
6. Считает текущее количество зданий по классам.
7. Random()%3 выбирает, какую категорию расширять.
8. При соблюдении порогов FUN_0081EC90 создаёт команду.

## FUN_0084D1D0 - colonize/expand planner

Эта функция находится в target scan, но тоже строит объекты:

1. Колонизация - FUN_0058A0B0.
2. Инфраструктура региона - FUN_00584E90.
3. Naval base - FUN_005853E0.
4. Новый завод - FUN_0084C470.
5. Найм/здание - FUN_00589840.

Подробности в 02_ai_targets_and_cb.
