# 09. Foreign Minister AI

Адреса VA. Основной декомпил - FUN_00845ad0_00845ad0.c. Источник имени - строки ai_foreignminister.cpp с ссылками из этой функции.

## Вход

    FUN_00845AD0(out, fromCountry, action, flagA, threshold, flagB, flagC, requiredTarget)

На практике действие приходит как дипломатический объект: action+0x20 - индекс, action+0x24 - вторая сторона.

## Быстрый отказ/ускорение

Сначала читается relation:

    relation = fromCountry+0x0BE8[action.countryIndex]

Функция строит пару сторон. Если relation+0x34 != 0, стороны меняются местами.

Быстрое правило:

1. Стороны должны существовать.
2. Нужен непустой список целей.
3. Если sender != owner relation, проверяется страна-получатель.
4. FUN_00936FC0 считает military/distance score.
5. Define DAT_012586DC+0x60+0x48 задаёт порог.
6. Define +0x4C задаёт минимальную долю.

Если условие выполнено, функция сразу переходит к выбору лучшей цели.

## Основной перебор

Если быстрый путь не сработал, создаются два CEventScope через FUN_008A8650:

| Scope | Заполнение |
|---|---|
| первый | fromCountry+0x1C/+0x20 |
| второй | action+0x20/+0x24 |

Далее перебирается список стран world+0x0ADC..0x0AE0, исключая REB. Для каждой страны проверяются условия действия:

- virtual trigger объекта+0x0D8+0x18;
- флаги параметров;
- CB-скан FUN_0092EDE0;
- существующий менеджер CB DAT_0131ACAC;
- объект не должен уже быть в relation+0x50.

## Оценка кандидата

Для каждого кандидата вызывается один из трёх планировщиков:

| Функция | Роль |
|---|---|
| FUN_00846C40 | общий scorer действия по стране |
| FUN_00846830 | выбор страны для offer/agreement |
| FUN_00846A70 | выбор региона/state |
| FUN_008465A0 | комбинированный выбор страна+регион |

FUN_00846C40 суммирует фиксированные веса:

| Условие | Вес |
|---|---:|
| уже выбранная цель param6 | +50000 |
| relation country+0x0BE8+0x20 существует | +20000 |
| один world/сфера | +10000 |
| одна столичная группа +0x50 | +5000 |
| для разных миров | +100000 |
| для разных столичных групп | +50000 |
| goal id 0x08A1 | military distance score |
| goal id 0x0264 | +1000000 |
| цель 0x06C2 и враг слабее по армиям | +50000 |
| цель 0x08A2 | colonial/naval score |

Дополнительный модификатор для цели 0x08A2 считается через DAT_01317CB8 и FUN_0047DEC0; итог клампится до 0..1000000.

## Финальная нормировка

Если специальный объект не найден:

    raw += FUN_009500E0
    base = country+0x1430 + threshold
    если base == 0, base = -1
    иначе base = base*1000/threshold

    coefficient:
      1000 по умолчанию
      500, если relation+0x34 == 0
      5 для civil страны

    final = raw * coefficient * (1000-base) / 1000 / 1000

Если специальный объект есть, добавляются военные проверки FUN_0042CA20/FUN_00951920 и пороговые правила из define DAT_012586DC+0x60+0x24.

## Random

Если score > 0 и param7 включён:

    score += (score/2/1000 - Random()%score/1000) * 1000

Победитель сохраняется, если bestScore < currentScore.

## Scorer-планировщики

### FUN_00846830

Перебирает страны и выбирает максимум FUN_00846C40. При успехе пишет action+0x10 и action+0x14.

### FUN_00846A70

Перебирает регионы цели и выбирает максимум FUN_00847B60. При успехе пишет action+0x28 = первая провинция.

### FUN_008465A0

Комбинирует country score FUN_00846C40 и region score FUN_00847B60. Итог total = regionScore + countryScore. Выбирает максимум и пишет action+0x10/+0x14/+0x28.
