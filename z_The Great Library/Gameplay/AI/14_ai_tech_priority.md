# 14. Research AI: tech priority internals

Адреса VA. Декомпилы лежат в decomp/v2game. Это продолжение 07_ai_research.md.

## FUN_00569920 - можно ли добавлять технологию

Декомпил показывает caller-контекст: ESI - объект технологии, EDI - страна.

Условия:

1. Текущий год должен быть не меньше tech+0x340:

       currentYear >= tech+0x340

2. Счётчик по категории должен быть меньше единицы:

       country+0x02B8 + tech+0x02E4*4 < 1

3. Вызывается virtual объект tech+0x02EC, слот +0x20.
4. Если virtual возвращает true, результат:

       country+0x02B8 + tech+0x02E4*4 > 0

   Иначе возвращается true.

Точная игровая семантика tech+0x2EC ещё требует runtime-подтверждения, но в FUN_00859710 это фильтр перед добавлением technology-кандидата.

## FUN_0056BC50 - множители технологии

Сигнатура:

    FUN_0056BC50(tech, outWeight, scope)

Базовый вес:

    weight = tech+0x0378

Список групп:

| Поле | Значение |
---|---:|
| tech+0x037C | начало списка |
| tech+0x0380 | конец списка |

Каждая группа:

| Смещение | Поле |
---|---:|
| +0x08..+0x0C | vector триггеров |
| +0x20 | вес, thousandths |

Алгоритм:

1. Для каждой группы все триггеры вызываются через virtual +0x18 со scope.
2. Если хотя бы один триггер false, группа пропускается.
3. Если все true:

       weight = weight * groupWeight / 1000

4. При падении веса ниже порога значение клампится.

Это соответствует факторам ai_chance/weight в скрипте технологии.

## FUN_0057A4C0 - категория, возраст и страна

Сигнатура:

    FUN_0057A4C0(tag, countryIndex)

EDI - объект технологии.

Шаги:

1. Страна:

       country = countryManager.data[countryIndex]

2. Модификатор категории:

       category = tech+0x0310+0x44
       modifier = country+0x0A60 + category*8

3. База:

       base = tech+0x02E8

4. Первичная нормировка:

       value = base * 1000 * 1000 / (modifier + 1000)

5. Возраст технологии:

       age = currentYear - tech+0x0340

   Если age > 0:

       define = DAT_012586DC+0x40+0xBC
       decay = age * 1000000 / define
       decay = min(decay, 1000)
       value = value * (1000 - decay) / 1000

6. Для цивилизованной/реформируемой страны, если страна уже имеет технологию в категории:

       value = value * DAT_012586DC+0x40+0xC0 / 1000

7. Итог клампится:

       if value < 1000: value = 1000
       return value / 1000

## Tech cache

FUN_00576FE0 создаёт объект tech cache:

| Поле | Значение |
---|---:|
| +0x06, +0x0D, +0x14, +0x1F, +0x26 | vector, capacity 0x1FF |
| +0x20 | вспомогательный объект |

FUN_0057AB10 устанавливает глобальный указатель:

    DAT_0125EADC = cache

Если прежний cache существует, вызывается деструктор FUN_00576D10.

FUN_00576D10 освобождает все векторы и вложенные объекты.

## Команда исследования

FUN_0058AD00 создаёт CStartResearchCommand.

Command ID:

    0x050F

Поля после CCommand:

| Поле | Значение |
|---:|---|
| +0x3C | param2, тег/страна |
| +0x40 | param3, индекс страны |
| +0x44 | param4, technology |

В FUN_00859710 команда отправляется через:

    dispatcher = *(world+0x0B24+0x44)
    dispatcher+0x38+0x18(command)

## Связь с FUN_00859710

Полный порядок приоритета кандидата:

1. Virtual tech+0x20 - базовая доступность.
2. FUN_0057A4C0 - категория, возраст и modifiers.
3. FUN_00569920 - точный фильтр возможности.
4. FUN_0056BC50 - script factors.
5. Random - взвешенный выбор.
6. FUN_0058AD00 - команда StartResearch.

## Статус

Подтверждено: условие FUN_00569920, цепочка множителей FUN_0056BC50, формула FUN_0057A4C0, кэш и команда исследования. Требует уточнения: точные имена полей tech+0x2EC и всех define-адресов.
