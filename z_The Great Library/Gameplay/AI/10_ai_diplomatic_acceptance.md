## FUN_00911BE0 - расчёт acceptance/причин

Вход: дипломатический объект и выходной буфер.

Ключевые поля объекта:

| Смещение | Значение |
|---:|---|
| +0x0C | from country index |
| +0x14 | to country index |
| +0x24 | виртуальные методы условия/цены |

Функция сначала строит список причин. Виртуальный метод +0x94 возвращает массив причин записями по 0x1C байт. Число причин определяет ветку форматирования:

| Число записей | Поведение |
|---:|---|
| 0 | FUN_00988F20 + FUN_009A8EE0 |
| 2 | FUN_0055D590 |
| 4 | FUN_00928600 |
| 6 | FUN_00928720 |

Затем выполняются проверки:

1. Если from == to, строка причины не добавляется.
2. Virtual +0x64 - базовая доступность.
3. Если target жив и relation war+0x34 == 0, проверяется virtual +0x70.
4. FUN_00516430 - дополнительная война/доступность.
5. Virtual +0x74/+0x78/+0x7C - следующие обязательные условия.
6. Ветеран/лидер правила читают target country+0x0CF4/+0x0CF5 и country+0x0CFC.
7. Virtual +0x54 и +0x60 дают требуемые значения ресурсов/отношений.
8. Virtual +0x50 даёт второй тип требования.

Если target - AI и действие не типа 0x08CB, вызывается FUN_006153A0 для оценки от target AI.

Функция не возвращает boolean: она заполняет tooltip/причины и итоговый счёт для UI.

## FUN_006164E0 - AI diplomatic value

Функция формирует окно reason по ключу chance_info_icon.

Основной расчёт:

    base = FUN_0083DB20(action...)

Далее value = base - 50, если base != -1000. Если base < 0, строка помечается негативной веткой, иначе позитивной. В обеих ветках вызывается локализация AI_DIPLOMATIC_VALUE.

FUN_0083DB20 - общий дипломатический score; он же используется foreign minister и military access.

## FUN_00838EB0 - crisis interest

Огромная функция, 1748 строк декомпила. Она вычисляет интерес страны к поддержке стороны кризиса.

Ключевые источники:

| Объект/поле | Роль |
|---|---|
| world GP1/GP2 | FUN_00425A40/FUN_00425AC0 |
| country+0x0E4C | регионы |
| country+0x0BE8 | relation matrix |
| object+0x14/+0x18/+0x1C/+0x20 | стороны кризиса |
| object+0x2C/+0x3C | списки целей/требований |
| world+0x0CF8+8 | активный crisis/war объект |

Функция:

1. Убирает текущую страну из временных списков сторон.
2. Строит scopes и lists через FUN_0043A750/FUN_004D61D0.
3. Для каждой стороны вызывает FUN_00952850 и FUN_0094BD40.
4. Дважды вызывает FUN_00845AD0 - foreign minister score для обеих сторон.
5. Добавляет DAT_01317CB8 как базовый modifier.
6. Считает отношение bestForeignScore / otherForeignScore.
7. Клампит delta до -2000.
8. Итог score = (initial + delta * 50) / 1000.
9. Положительный score добавляется в side A, отрицательный в side B.
10. Подробные AIREASON-строки создаются через FUN_009885D0/FUN_0094C240/FUN_0042C180.

## FUN_0061CA40 - crisis back/UI decision

Функция огромная, 3427 строк. Она связана со строками CRISIS_AI_WANTS_TO_BACK_1/2/3, но также обрабатывает фильтры/сортировку дипломатического интерфейса:

- filter_value;
- sort_by_value;
- country/world state;
- активные crisis-объекты.

В AI-ветке она вызывает:

| Функция | Роль |
|---|---|
| FUN_00911BE0 | acceptance/причины |
| FUN_00838EB0 | crisis interest |
| FUN_00539630/FUN_00938AD0 | военные/дипломатические проверки |
| FUN_0061B0D0/FUN_0061AFF0 | состояние кризиса |
| FUN_00952F10/FUN_00954510/FUN_009542C0 | оценщики сторон |

Полное документирование UI-ветки относится к Interface; AI-часть подтверждена по вызовам выше.
