# 00. Архитектура ИИ

Адреса VA, если не указано RVA. Сырые декомпилы - в decomp/v2game.

## Верхний уровень

Игровой день FUN_006859C0 вызывает два страновых прохода:

    FUN_00508590(country)  налоги, бюджетные выплаты, реформы
    FUN_005091A0(country)  экономика и часть социальных процессов

Отдельно от дневного мира работает покадровая очередь ИИ:

    FUN_006874C0(queue)
      извлекает узел страны из очереди
      если country+0x208 != 0, вызывает FUN_0081E9E0

Список живых AI-стран и human-флаг:

    session+0x0AEC..0x0AF0
    элемент по индексу страны: 0 = AI, непустой тег = human

Менеджер стран:

    DAT_012587E4 = 0x012587E4
    count = *(manager)
    data = *(manager+4)
    country[i] = data[i*4]

AI-объект:

    country+0x0208

Основные поля AI-объекта:

| Смещение | Значение |
|---:|---|
| +0x30 | тег страны, 4 байта |
| +0x34 | индекс страны |
| +0x38 | указатель на country |
| +0x77, +0x79 | список целей/заданий |
| +0x89 | список отложенных объектов |
| +0xE | индекс страны, дубль |
| +0xF | активный флаг |

## Ежедневный диспетчер AI

FUN_0081E9E0 пропускает REB и работает только для стран с провинциями:

    FUN_00821510  приоритеты
    FUN_005DCAC0  армии/юниты
    virtual country+0x0188+0x24  планировщик строительства
    FUN_005DCB70  восстановить контекст
    FUN_00820DF0  дипломатия
    FUN_0081F3B0  фабрики и субсидии
    FUN_0081FB00  постройка фабрик
    FUN_00820760  провинциальные здания
    FUN_0081E5B0  реформы
    FUN_0081E280  армия
    FUN_00821190  решения

Функция вызывается из FUN_006874C0 через virtual country+0x0188+0x24; планировщик - FUN_004A5170.

## Подсистемы

| Том | Подсистема |
|---|---|
| 01 | ежедневный диспетчер |
| 02 | решения и триггеры |
| 03 | цели войны и дипломатии |
| 04 | фабрики и строительство |
| 05 | события и авто-выбор опций |
| 06 | модовые хуки и ускорение |

## Ключевые глобалы

| Адрес | Назначение |
|---:|---|
| 0x012587E4 | менеджер стран |
| 0x012588E8 | мир/сессия |
| 0x01319730 | глобальный менеджер решений |
| 0x0131BB34 | глобальный список POP type |
| 0x01258A48 | список строительных запросов |
| 0x012588E8+0x0AEC | human/AI флаги по индексу страны |

## Правило адресации

Константы в V2DLL часто хранятся как RVA. Ghidra использует VA:

    VA = RVA + 0x400000

Например DecisionCull kAiFunction = RVA 0x421190, но Ghidra-функция - VA 0x00821190.
