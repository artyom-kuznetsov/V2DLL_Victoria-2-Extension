# 12. Military AI: FUN_008500A0

Адреса VA. Основной декомпил - FUN_008500a0_008500a0.c. Функция выбирает, куда направить армии против активной цели, и при необходимости отменяет текущий приказ.

## Вход и контекст

Функция вызывается из target scan FUN_0084B0F0 для активной записи country+0x07B4.

Поля AI/target:

| Объект | Смещение | Значение |
|---|---:|---|
| country | +0x07B4 | список активных военных задач |
| задача | +0x1D | страна-владелец задачи |
| задача | +0x37 | страна-цель |
| задача | +0x2C | virtual +0x2C возвращает структуру target |
| AI country | +0x0208 | AI object |
| AI object | +0x34/+0x38 | тег и индекс страны |

Функция также читает param+0x34/+0x38 - тег и индекс страны из AI object.

## Фильтр активной задачи

Задача пропускается, если любое условие истинно:

| Условие |
|---|
| задача+0x1D == 0 |
| virtual задача+0x38 != true |
| задача+0x37 == 0 |
| relation target+0x1B4 != 0 |
| задача уже есть во временном списке |

## Разделение армий

Для задачи читаются два списка юнитов:

| Источник | Смещение |
|---|---:|
| сторона A задачи | target owner +0x10+0x20 |
| сторона B задачи | target enemy +0x14+0x20 |

FUN_0057AAB0 добавляет узел во временный список. FUN_004E94A0 клонирует один список в другой, если обнаружено участие AI в обеих сторонах.

Дальше province+0x0EC - список армий в провинции. Владелец армии определяется так:

1. Если army+0x0A0 != 0, это прямой указатель/индекс провинции-владельца.
2. Иначе, если army+0x0EC >= 1, читается юнит type id, затем таблица world+0x2238.
3. Иначе владелец считается нулевым.

Армия попадает в enemy-список, если:

    army+0x0C4 != aiCountryIndex
    relation(ai, armyOwner)+0x20 == 0
    и выполняется одно:
      relation(ai, armyOwner)+0x34 != 0
      армия принадлежит REB
      AI сам REB

Иначе армия попадает в friendly-список.

## Оценка сил

FUN_005946A0 суммирует +0x1C у юнитов, прошедших virtual check FUN_00414BD0. FUN_005DB9B0 суммирует +0x10 у армий, прошедших virtual +0x38.

Ключевые переменные:

| Переменная | Значение |
|---|---|
| local_78 | сила стороны A + FUN_005946A0 |
| local_58 | сила стороны B + FUN_005946A0 |
| local_84 | знаменатель FUN_005DB9B0, минимум 1 |
| local_94 | local_84 / знаменатель |
| local_28 | сумма score friendly армий |
| local_70 | сумма score enemy армий |

Virtual army+0x5C возвращает score в thousandths; он делится на 1000.

Проверка готовности:

    если local_94 < DAT_00F1783C, цель пропускается

Формула сравнения:

    diff = local_58 - local_78

    если diff <= 0:
        enemyPower = enemyScore
        если diff < 0:
            friendlyPower = (1 - diff / 4.5) * friendlyScore
    иначе:
        enemyPower = (diff / 18.0 + 1.0) * enemyScore
        friendlyPower = friendlyScore

Если в enemy-списке есть REB:

    enemyPower *= 0.7

Условие атаки/переброски:

    (enemyPower / friendlyPower) * local_94 > DAT_00F177E0

## Выбор лучшей провинции и армии

Перебираются провинции target country:

    state+0x5C+0xC8..0xCC, записи 0x24

Провинция пропускается:

| Условие |
|---|
| state type == 4 |
| province+0x2A == 0 |

Для каждой армии в province+0x0EC считается score:

| Условие | Score |
|---|---:|
| army+0x0C4 == aiCountry | army+0x40 |
| другой владелец и relation+0x20 != 0 | army+0x40 * 0.5 |
| другой владелец и relation+0x20 == 0 | армия игнорируется |
| province+0x12C == aiCountry | +2 |
| province owner == 0 | итог * 0.5 |

Выбирается максимум. Переменная local_20 - лучшая армия.

## Переброска

Для каждой friendly армии:

1. Требуется army+0x0C4 == aiCountry.
2. FUN_005CC3E0 должен вернуть false.
3. Если army+0x0DC == target country, вызывается FUN_00852A00 - CSafePathFind.
4. Иначе, если army+0x104 == 0:
   - army+0x0A0 = 0;
   - создаётся CCancelMovementCommand через FUN_005DF690;
   - команда отправляется через world+0x0B24+0x38+0x18.
