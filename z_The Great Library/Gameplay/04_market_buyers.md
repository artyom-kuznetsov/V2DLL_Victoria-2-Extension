# 04. Покупатели рынка: государство, фабрики, POP

Продолжение 00_market_cycle. Адреса VA. Сырые декомпилы - в decomp/v2game.

## Рабочие пулы прохода

На итоговом проходе FUN_00484060 используются два временных пула:

| Пул | RVA | VA |
|---|---:|---:|
| домашний/внутренний | 0xFF2500 | 0x13F2500 |
| мировой | 0xFF2450 | 0x13F2450 |

Холдер товара:

| Смещение | Поле |
|---:|---|
| +0x08 | byte-слоты товаров |
| +0x48 | vector int64, 15 дробных бит |
| +0x4C | конец вектора |

Правило приоритета подтверждено декомпилом и модовым хуком: сначала товар берётся из домашнего пула, остаток - из мирового. Убыль пулов превращается в выручку производителей в FUN_00488080.

## Общая последовательность

    FUN_00484060(country, pass)
      FUN_00482FF0  снабжение фабрик и строительных проектов
      FUN_00487410  государственные закупки
      FUN_00485E40  население и фабрики
      FUN_00488080  продажа/выручка фабрик

Порядок имеет значение. Патч BUILDING_GOODS_CONSUMPTION вставляет закупки модовых зданий сразу после FUN_00487410, чтобы они конкурировали с государством, но не обходили POP и фабрики.

## Государственные закупки FUN_00487410

Файл: FUN_00487410_00487410.c.

Вход: рыночный контекст, страна, флаг статистики/истории. Функция идёт по глобальному списку товаров DAT_012587F0 и для каждого товара выполняет один цикл из трёх шагов.

Ключевые поля страны:

| Смещение | Поле |
|---:|---|
| +0xE78 | казна, int64 fixed15 |
| +0xF7C | byte-слоты желаемого резерва |
| +0xFBC | vector желаемого резерва |
| +0x11CC | vector государственного склада |
| +0x118C | byte-слоты предложения/доступности |
| +0x12A0 | vector требований, записи 0x18 |
| +0x128C | начало вектора требований |
| +0x1290 | конец вектора требований |
| +0x1568 | флаг задолженности/недостатка денег |

Запись требования:

| Смещение | Поле |
|---:|---|
| +0x08 | требуемое количество, int64 |
| +0x0C | альтернативное количество/цель |
| +0x10 | флаг активности требования |

Алгоритм по товару:

1. Если требование отключено, считается нулевым.
2. Из требования вычитается текущий склад: это фактическая потребность.
3. Потребность добавляется в рыночный спрос. Слоты спроса - market+0x1D8, вектор - market+0x218.
4. Количество ограничивается домашним и мировым пулами.
5. Домашняя часть покупается первой.
6. Мировая часть покупается второй.
7. Каждый купленный объём вычитается из пула и добавляется в склад страны.
8. При флаге истории FUN_0047DA90 фиксирует факт продажи, а вектор market+0x614 получает купленный объём.

Оплата идёт по текущей цене market+0x2C8. Если казна меньше стоимости одной единицы, код делает один из двух шагов:

| Условие | Поведение |
|---|---|
| world+0x0D1C == 0 | казна поднимается до стоимости единицы |
| world+0x0D1C != 0 | вызывается FUN_00522910, кредитный/бюджетный путь |

Затем объём покупки масштабируется под доступную казну, а флаг country+0x1568 показывает недостаток средств.

## Снабжение фабрик FUN_00482FF0

Файл: FUN_00482ff0_00482ff0.c.

Вход: рынок, страна, фабрика. Это не абстрактная очередь строительства: FUN_00484060 вызывает функцию для конкретной открытой фабрики.

Подтверждённые поля фабрики:

| Смещение | Поле |
|---:|---|
| +0x18 | тип фабрики |
| +0x20 | уровень |
| +0xD8 | бюджет/резерв проекта, int64 |
| +0x150 | деньги фабрики |
| +0x158 | вчерашние закупки входа |
| +0x180 | субсидия |
| +0x184 | счётчик остановки |
| +0x208 | зарезервированные инвестиции/деньги проекта |

Функция:

1. Корректирует бюджет проекта и ограничивает его глобальными defines.
2. Берёт государственную базу финансирования и доступную казну.
3. Делит деньги фабрики на константу DAT_00F0B2D0/0xD4 для расчёта целевого объёма.
4. При включённой субсидии учитывает вчерашние закупки +0x158.
5. Покупает входные товары через рыночные пулы.
6. Если закупок нет и фабрика не субсидируется, увеличивает счётчик остановки +0x184.
7. При достижении 11 остановок на уровне 1 уменьшает уровень.
8. Вызывает FUN_004F4AC0 для фактической закупки и FUN_004F50C0 для счётчика.
9. Записывает затраты в +0x158 и добавляет продажную сумму в агрегат страны.

## Население и фабрики FUN_00485E40

Файл: FUN_00485E40_00485E40.c.

Функция очень большая и объединяет две задачи:

- расчёт потребностей POP;
- закупки POP и фабрик из рабочих пулов.

Подчинённое ядро покупки POP - FUN_00485390, описано в 03_pop_needs. Модификаторы страны передаются в цену набора; товаров в наборе несколько категорий.

Точный полный проход FUN_00485E40 ещё не полностью размечен, но вызовы FUN_00485390/FUN_00485D50 и рыночные пулы декомпилом подтверждены.

## Выручка фабрик FUN_00488080

Файл: FUN_00488080_00488080.c.

После покупок функция:

1. Проходит страны с провинциями.
2. Для каждого региона проходит цепочку фабрик state+0x60, next = node+0x224.
3. Для открытой фабрики считает продажу произведённого товара.
4. Накапливает выручку и вызывает FUN_004F4B30.
5. Возвращает деньги в казну страны и в агрегаты верхней панели/бюджета.

Таким образом, рынок делает полный круг: фабрика покупает вход, потом её выход продаётся, и только затем начисляются зарплаты, излишки владельцам и убытки.

## Модовая закупка зданий

BUILDING_GOODS_CONSUMPTION использует ту же модель:

    сначала домашний пул, затем мировой;
    оплата по текущей цене;
    ограничение казной;
    регистрация спроса market+0x218;
    учёт убыли пула как выручки производителей.

Хук ставится на VA 0x0048466B, сразу после FUN_00487410.
