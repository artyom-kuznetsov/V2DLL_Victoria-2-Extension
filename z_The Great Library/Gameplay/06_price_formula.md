# 06. Формула рыночной цены

Адреса VA. Основной декомпил - decomp/v2game/FUN_00482930_00482930.c.

## Данные рынка

| Смещение | Поле |
|---:|---|
| +0x050 | vector предложения/базового пула |
| +0x010 | byte-слоты вектора +0x050 |
| +0x218 | vector спроса, int64 |
| +0x1D8 | byte-слоты спроса |
| +0x2C8 | vector текущих цен, int64 |
| +0x288 | byte-слоты текущих цен |
| +0x334 | очередь изменений цены |
| +0x338 | размер очереди |
| +0x33C | флаг отложенного узла |
| +0x340 | время последнего добавления |

Все товары индексируются byte-слотами. Индекс 0 означает отсутствие записи в векторе.

## FUN_00482930 - обновление цен

Функция обрабатывает список записей движения товара. Каждая запись содержит индекс товара, флаг активности и количество.

Подтверждённый порядок:

1. Формирует внутренний список активных товаров.
2. Для записи читает базовое предложение из market+0x050 и спрос из market+0x218.
3. Считает отношение demand / supply.
4. Вызывает FUN_00482610 для расчёта целевой цены.
5. Умножает количество записи на коэффициент.
6. Сравнивает с текущей ценой market+0x2C8.
7. Добавляет или обновляет запись очереди market+0x334.
8. Записывает текущую цену через slot market+0x288.

Существенное подтверждение из декомпила: цена тянется к целевому значению, а не заменяется мгновенно. Дневной шаг в ванили задан глобальной константой RVA 0xE5B9E0.

## Модовые шаги изменения

### TRADE_PRICE_DELTA_PERCENTUAL

Точка: RVA 0x082BA9, возврат RVA 0x082BAE.

Входные регистры:

    ECX:EAX - текущая цена
    EDX - целевая цена

Мод заменяет фиксированный дневной шаг на долю текущей цены. По умолчанию PRICE_BASIS_POINTS = 25, то есть 0.25% в день. У дешёвых товаров нулевое округление предотвращается минимальным шагом.

### TRADE_PRICE_DELTA_EXPONENTIAL

Тот же хук. Шаг зависит от расстояния между текущей и целевой ценой через сдвиги, поэтому движение ускоряется при большом разрыве. Флаги взаимоисключающие; при обоих включённых ключах применяется exponential.

### TRADE_MAX_PRICE_20X_MULTIPLIER

Байтовый патч меняет double по RVA 0x0A45C28. Константа читается в FUN_00482930 и FUN_0082F430.

Проверенный статус:

- константа действительно влияет на ограничение;
- статически не подтверждено, почему видимый потолок в Trade-окне может оставаться x10;
- вероятна вторая нелинейная проверка или отдельный UI-предел.

## Что подтверждено

1. Векторы цен и спроса.
2. Отношение demand/supply как основа целевой цены.
3. Наличие отложенной очереди изменений.
4. Точка хука дневного шага.
5. Порядок обновления цены до покупок в FUN_00489990.
