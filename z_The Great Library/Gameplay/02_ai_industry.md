# 02. AI: расширение фабрик и постройка зданий

Адреса VA. Сырые декомпилы - в decomp/v2game.

## Выбор кандидата на расширение

Файл: FUN_00857530_00857530.c. Запрошенный адрес 00857614 находится внутри этой функции.

Функция перебирает регионы и существующие фабрики подходящего типа. Для каждой кандидатуры:

1. Проверяет общий гейт постройки через FUN_004D04B0.
2. Ищет фабрику типа в цепочке state.
3. Пропускает кандидата, если уже расширяется: очередь/счётчик +0x17C != 0.
4. Считает score по уровню, свободной мощности и случайной добавке.
5. Возвращает лучший state building.

Мод FACTORY_AI_SPAM_FIX вставляет дополнительный фильтр на VA 0x00857614. Расширение разрешено, если занятость достигла ai_factory_expand_min_staffing процентов от максимальной мощности:

    employees * 100 >= max_workforce * level * min_percent

Значение по умолчанию 90%, 0 отключает фильтр. Без фильтра AI часто закладывает расширение в полупустую фабрику.

## Выбор провинции для постройки

Есть два AI-селектора:

| Функция | Файл | Роль |
|---|---|---|
| FUN_008577B0 | FUN_008577b0_008577b0.c | выбор провинции для здания из request+0x80 |
| FUN_008580E0 | FUN_008580e0_008580e0.c | выбор провинции для здания из request+0x78 |

Обе функции:

1. Идут по регионам страны и провинциям региона.
2. Проверяют, что здание можно строить в провинции через FUN_00511EF0.
3. Учитывают деньги и бонус/расстояние.
4. Возвращают провинцию-кандидата.

В ванили нет ограничения одна naval_base на регион, поэтому AI может закладывать базы во все портовые провинции.

## PATCH_AI_NAVAL_BASE_LIMIT

Мод перехватывает три call-сайта FUN_00511EF0 внутри AI-селекторов:

| Call site VA |
|---:|
| 0x00857983 |
| 0x00857D02 |
| 0x00858282 |

Для naval_base в новой провинции считается, сколько других провинций региона уже имеют базу уровня >= 1 или строят её. Если это число достигло ai_naval_base_max_provinces_per_state, FUN_00511EF0 принудительно возвращает 0.

Не ограничиваются:

- улучшение существующей базы;
- игрок;
- капиталисты;
- здания, кроме naval_base.

Значение берётся из common/defines_v2dll.txt. 0 отключает ограничение.

## AI decisions

Отдельный блок решений уже реализован в DLL, но нуждается в отдельном томе документации.

Подтверждённые адреса из исходника:

| Адрес VA | Роль |
|---:|---|
| 0x0044B0F0 | AI scan / decision loop |
| 0x008A773C | глобальный AI-слот |
| 0x00449120 | eval/AND-триггер контекст |
| 0x00A2773C | AI decision manager |

Механика PATCH_CULL_DECISION_CHECKS:

1. Делает на страну частный список решений.
2. Пропускает решения, отсекаемые дешёвыми потенциальными условиями: тег страны, AI-гейт, флаги.
3. Не меняет список решений игрока.
4. PATCH_PARALLEL_DECISIONS может заранее готовить списки в рабочем потоке, но остаётся детерминированным и сверяется с оригинальным порядком.

Полная карта trigger-классов, potential и allow ещё не оформлена.
