# 08. FUN_006859C0: дневной тик мира

Адреса VA. Основной декомпил - decomp/v2game/FUN_006859c0_006859c0.c. Это верхний оркестратор игрового дня; экономика, POP и рынок - его подфазы.

## Основные контейнеры мира

| Смещение world | Поле |
|---:|---|
| +0x0ACC..+0x0AD0 | vector провинций |
| +0x0ADC..+0x0AE0 | vector стран |
| +0x0B0C | время мира в часах; день = время / 24 |
| +0x0B3C | список POP type / системных объектов |
| +0x0B88..+0x0B8C | vector военных/союзных группировок |
| +0x0B94 | флаг состояния войны/мира |
| +0x0B98..+0x0B9C | вектор отложенных событий/команд |
| +0x0BCC | рынок |
| +0x0CF4 | глобальное состояние кампании/даты |
| +0x0CF8 | список активных войн/кризисов |
| +0x0D11 | флаг, отключающий часть newspaper/статистики |
| +0x0D1C | флаг кредитного пути государственных закупок |

Списки читаются как begin..end; если старший байт end меньше begin, размер в декомпиле маскируется как беззнаковый.

## Подготовка дня

Порядок в начале FUN_006859C0:

1. FUN_006840F0 - подготовка дневного контекста.
2. Обход списка world+0x0B3C и FUN_0093C980.
3. Ленивое создание глобального массива POP type DAT_0131BB34.
4. Для каждого элемента этого массива FUN_0096F7C0.
5. Для каждой страны snapshot казны:

       country+0x0E80/+0x0E84 = country+0x0E78/+0x0E7C

6. Для каждой провинции FUN_004B9C60 и FUN_004B1A10.
7. FUN_00685620 - периодический UI/audio pump, чтобы фоновые батчи не блокировали отрисовку.

Затем функция предгенерирует 1000 значений Mersenne Twister в локальный массив. Это ключевой момент детерминизма: батчевые проходы берут случайность из подготовленного массива, а не в произвольном порядке потоков.

## Предварительный страновой проход

Если стран больше 5, функция запускает подготовительный цикл:

    for countryIndex = 1; countryIndex < countryCount; ++countryIndex
        FUN_00508590(country)
        FUN_00685620()

FUN_00508590 - бюджетно-налоговый тик страны: налоги, субсидии, выплаты POP и реформы. Экономический тик FUN_005091A0 идёт позже. Полный разбор - 09_country_budget_tick.

## Дата и батчи провинций

Функция вычисляет день года и номер месяца из world+0x0B0C, используя таблицу длины месяцев DAT_00F1027C/DAT_00F10280.

Потом вызывает FUN_0068F3F0 для батчевой обработки провинций. Количество провинций на батч:

    max(1, provinceCount / 12)

Таким образом игра распараллеливает провинции, но сохраняет фиксированный порядок результатов и предзаготовленную случайность.

## Страновой экономический тик

После провинциального батча:

    for countryIndex = 1; countryIndex < countryCount; ++countryIndex
        FUN_005091A0(country)
        FUN_00685620()

FUN_005091A0 - главный дневной тик страны, включая налоги, RGO-доход, социальные процессы и вызов FUN_00538200. Подробности в 05_treasury_budget.

## Постстрановые процессы

После стран вызываются:

| Вызов | Уровень |
|---|---|
| FUN_004F5BF0 | для каждой страны |
| FUN_004BA780 | для провинций, где province+0x012C != 0 |
| FUN_00489990 | рынок, один итоговый дневной проход |
| FUN_005B5180 | пост-рыночная фаза мира |
| FUN_0068F4C0 | второй батчевый проход стран |
| FUN_005417D0 | для каждой страны |
| FUN_004E1E20/FUN_004E5B50 | отложенные события из world+0x0B98 |
| FUN_008A7CD0 | newspaper/статистический объект |
| FUN_004D3BB0 | цепочки регионов |
| FUN_0042A130 | глобальная сводка |
| FUN_0068D250 | пересортировка/пересчёт стран |

Каждый крупный блок перемежается FUN_00685620.

## FUN_0068BF00 - стартовые проходы рынка

Файл: FUN_0068bf00_0068bf00.c.

Функция инициализирует экономику без полноценного игрового дня:

    FUN_00520150(country) для всех стран
    FUN_0068D250(world, 0)
    FUN_00482930(market, 1)
    FUN_004808D0(market, 1, 0)
    FUN_0068D950(world)
    5 x FUN_00489990(market, 1, i)
    FUN_0068DC70(world)

Это пять подготовительных проходов рынка. Они прогревают цены и пулы до начала игры. Игровой дневной проход FUN_006859C0 после этого вызывает FUN_00489990 ещё раз как итоговый.

## FUN_0068D250 - пересчёт/ранжирование стран

Файл: FUN_0068d250_0068d250.c.

Функция строит список живых стран, фильтрует мёртвые и присваивает рейтинговые индексы:

| Поле страны | Назначение |
|---:|---|
| +0x1404 | рейтинг 4 |
| +0x1408 | рейтинг 1 |
| +0x140C | рейтинг 2 |
| +0x1410 | рейтинг 3 |
| +0x1400 | дата/таймер исключения |

Максимальное количество обрабатываемых стран берётся из глобального define DAT_012586DC+0x40+0x1C. Функция также вызывает FUN_0068C660, FUN_00539510, FUN_005395A0 и FUN_0053D680 для смены статуса страны. Точная игровая номенклатура - великие державы, вторичные державы или исключение из рейтинга - пока не сопоставлена с локализацией.

## Глобальная денежная масса

В конце FUN_006859C0 функция суммирует деньги всех уровней:

| Источник | Поле |
|---|---|
| страна | +0x0E78 казна |
| state | +0x0228 сбережения |
| фабрика/state building | +0x0210 и related значения через FUN_004F5100 |
| construction project | +0x00B8 активного объекта |
| POP | +0x0180 наличные |

Также учитываются массивы по 12 слотам из country+0x00A0 и глобальные агрегаторы DAT_0125B950/DAT_0125B978.

Итог записывается в:

    DAT_0125B950 / DAT_0125B954
    DAT_0125B978 / DAT_0125B97C

Затем вызываются FUN_0068E390 и FUN_00683CE0. Первый обрабатывает изменение состояния войны и сообщения WAR_GAIN_GW_STATUS, второй обходит список world+0x2A88.

## FUN_00685620 - неэкономический pump

Функция не меняет симуляцию. Она проверяет world+0x0B20, коэффициент скорости из настроек и вызывает виртуальный метод world+0x0B24+0x100 и FUN_009DF2B0, если пришло время обновить интерфейс/звук.

## Значение для мультиплеера

FUN_006859C0 фиксирует порядок почти всей детерминированной симуляции:

1. Snapshot казны.
2. Предзаготовка 1000 RNG значений.
3. Батчевая обработка провинций.
4. Батчевая обработка стран.
5. Один рыночный проход.
6. Постобработка и события.
7. Пересчёт рангов и денежной массы.

Любой мод, вызывающий Random(), изменяющий казну или переставляющий контейнеры вне этих фаз, может вызвать рассинхрон. Поэтому DLL-патчи стараются вставляться в существующие точки FUN_005091A0/FUN_00489990, а не создавать собственные недетерминированные проходы.

## Статус

Подтверждено: порядок фаз, массивы стран/провинций, snapshot казны, батчи, вызов рынка, стартовые проходы и глобальные суммы денег. Требует доработки: точные имена функций FUN_0068F3F0/FUN_0068F4C0, номенклатура рейтингов и полный разбор post-market списков world+0x0B98.
