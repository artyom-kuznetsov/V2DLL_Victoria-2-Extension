## Сырые декомпилы

decomp/v2game содержит 47 файлов FUN_*.c и callers.txt, полученных Ghidra 12.1.2. Имя файла - адрес функции, поле requested в первой строке - адрес, по которому функция искалась.

Важно: Ghidra иногда склеивает смежные функции или ошибочно расширяет тело. Поэтому каждый вывод сопоставлен с сигнатурами и рабочими хуками DLL.
