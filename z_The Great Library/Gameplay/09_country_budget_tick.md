# 09. FUN_00508590: бюджетно-налоговый тик страны

Адреса VA. Основной декомпил - decomp/v2game/FUN_00508590_00508590.c.

Функция вызывается из FUN_006859C0 до FUN_005091A0. Ранее мы называли её только подготовительной; декомпил показывает, что это активный бюджетно-налоговый тик. Корректнее разделять так:

    FUN_00508590 - налоги, бюджетные выплаты, реформы, содержимое армии
    FUN_005091A0 - экономика страны, RGO, социальные/политические процессы

## Подготовка и отложенные команды

| Условие/объект | Действие |
|---|---|
| country+0x15BC != 0 | сброс флага и FUN_005448B0 |
| country+0x010C != 0 | вызов виртуального метода отложенного объекта |
| country+0x1418..0x141C | текущий список приоритетных стран/держав |
| country+0x1428/+0x142C | выбранный объект фокуса; при удалении провинций сбрасывается |

FUN_0051FD10 обновляет кэш отношений. FUN_0054BC10 чистит список приоритетных стран: если целевой объект больше не существует, запись убирается, а при пустом фокусе relation+0x40 переводится в 2.

## Военные очереди и содержимое

Если у страны есть провинции, функция:

1. Очищает country+0x0890 и country+0x08A0.
2. Обходит глобальный список запросов DAT_01258A48.
3. Распределяет объекты по типам:
   - type 1 - добавляется в country+0x0890;
   - type 2/3 у цивилизованной страны или type 4/5 у нецивилизованной - FUN_0068F390;
   - остальные типы обрабатываются отдельными ветками.
4. Для страны с провинциями или для REB вызывает:
   - FUN_00515490;
   - FUN_0050E540;
   - FUN_0050EA30.

Эти три функции образуют военный/административный ежедневный блок. Полная семантика каждой ещё требует отдельного тома.

## Таймер реформы/события

Условие:

    world_time > country+0x0E9C + define * 0x2238

Если таймер истёк, функция лениво создаёт объект DAT_0125A69C через FUN_008B0060 и ищет совпадение в country+0x04D8. Если объект не найден, вызывается FUN_00511340(country, 1).

FUN_00511340 очищает список country+0x0E8C, вычитает стоимость каждого объекта из глобального бюджета country+0x0E88+0x10/+0x18 и вызывает деструктор. Это отложенные проекты/заказы.

## Расчёт налогов и базового дохода

Функция проходит провинции country+0x09D8. Для каждой провинции с RGO/рабочими записями рассчитывается доход, затем трижды вызывается FUN_00439630 для трёх налоговых полей country+0x00A0.

Каждый результат добавляется:

    country+0x0E78 - казна
    country+0x0E88+0x28 - агрегат бюджета

Суммарный доход сохраняется в lVar17 и используется для выплат.

Затем FUN_00523C30 формирует расходную часть, а отрицательный итог не опускается ниже нуля.

## Перераспределение и субсидии

После расчёта дохода функция обходит страны country+0x0BE8:

| Условие | Действие |
|---|---|
| relation+0x2C пуст или другая метка | возможна разовая выплата через FUN_005238D0 |
| relation совпадает по метке | выплата доли define DAT_012586DC+0x30+0x38C |
| получатель существует | деньги добавляются в получатель+0x0E78 и его бюджетный агрегат +0x38 |

Это путь субсидий/дани. Отправителю уменьшается остаток бюджета, получателю увеличивается казна.

## Выплаты POP

Функция лениво получает список POP type DAT_0131BB34 и вызывает:

    FUN_0050B9B0(country, typeCount, typeList, playerFlag)

FUN_0050B9B0 делит бюджетные статьи между типами POP. Подробности в 03_pop_needs. Здесь важно, что выплаты происходят в FUN_00508590, то есть до POP-рынка FUN_00485E40 и до экономического тика FUN_005091A0.

## Реформы/решения

Функция обходит country+0x15DC..0x15E0:

1. FUN_004467F0 проверяет доступность варианта.
2. FUN_00446A30 обрабатывает выбранную реформу.
3. Поле option+0x44/+0x45 используется как флаг уже применённого/текущего варианта.
4. Если список опций закончился, он очищается.
5. Для игрока ставится флаг обновления UI через world+0x0B24+0x24.

## Игровые расходы на здания

Если обрабатываемая страна совпадает с локально сохранённым playerIndex iVar4, функция проходит регионы и таблицу country+0x1514..0x1518. Для каждой записи:

    FUN_004F53E0(option)
    FUN_004D2FF0(option)

Это административные расходы/ускорение проектов на уровне зданий регионов. Поэтому флаг игрока влияет на отображение и возможно на ветку обработки, но базовые налоги и выплаты идут для всех стран.

## Статус

Подтверждено декомпилом: налоги и treasury+0x0E78, субсидии/дань, вызов FUN_0050B9B0, реформы и военные очереди. Требует доработки: полные формулы FUN_00439630, семантика всех типов запросов DAT_01258A48 и точная связь FUN_00523C30 с категориями расходов.
