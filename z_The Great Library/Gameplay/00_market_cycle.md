# 00. Рынок и дневной торговый цикл

Все адреса - VA в Ghidra; RVA = VA - 0x400000. Сырые декомпилы лежат в decomp/v2game.

## Основной граф

    FUN_00489990  рынок, дневной проход
      FUN_00482930  обновление цен/очереди изменений
      FUN_004808D0  дневной проход по странам/стейтам
      FUN_00484060  собственно торговый проход

Финальный вызов из игрового дня - FUN_00489990(market, 11, ...). Параметр 11 - финальный проход. Часть подготовительных проходов использует меньшие номера; патч BUILDING_GOODS_CONSUMPTION вставляет государственные покупки сразу после FUN_00487410 и до FUN_00485E40.

## FUN_00489990 - дневной рынок

Файл: FUN_00489990_00489990.c.

Порядок на верхнем уровне:

1. Готовит рыночные массивы/очереди цен.
2. Вызывает FUN_00482930.
3. Вызывает FUN_004808D0 для агрегатов по странам.
4. Вызывает FUN_00484060 - реальный торговый проход.
5. После прохода очищает/обновляет суточные контейнеры рынка.

## Пулы товаров

На первом проходе FUN_00484060 лениво создаёт глобальные пулы CGoodsPool. Ключевые адреса:

| Пул | RVA | VA |
|---|---:|---:|
| мировой остаток | 0xFF2450 | 0x13F2450 |
| внутренний/домашний пул | 0xFF2500 | 0x13F2500 |
| служебные пулы прохода | рядом 0x13F1A98, 0x13F24A8, 0x13F2558 | те же VA |

Это глобальные данные прохода, а не состояние страны.

## FUN_00484060 - покупательский проход

Файл: FUN_00484060_00484060.c.

Проходит страны, у которых есть провинции. Для каждой страны:

1. Делит доступный бюджет по товарам.
2. Идёт по списку регионов/фабрик.
3. Для открытой фабрики выполняет три условия: level > 0, stop counter < 11, closed flag = 0.
4. Вызывает FUN_00482FF0 - покупки проектов/строительства.
5. Вызывает FUN_00487410 - государственные покупки.
6. Вызывает FUN_00485E40 - покупки населения и фабрик.
7. В отладочном режиме пишет TOTAL_LEFT_ON_WORLD_MARKET_NOT_BOUGHT.

Порядок важен: проекты раньше государства, государство раньше POP и фабрик. Модовые хуки сохраняют этот порядок.

## FUN_00482930 - цены

Файл: FUN_00482930_00482930.c.

Функция обновляет товарные цены и очередь изменений. Ванильный дневной шаг - фиксированная константа по RVA 0xE5B9E0. DLL-патчи TRADE_PRICE_DELTA_PERCENTUAL и TRADE_PRICE_DELTA_EXPONENTIAL меняют место RVA 0x082BA9 внутри этой функции.

Статус: подтверждены место шага и общий характер прохода; полная формула спрос/предложение требует отдельного документа с разбором массивов товара.

## FUN_00488080 - выручка фабрик

Файл: FUN_00488080_00488080.c.

Функция идёт после покупок и по открытым фабрикам считает выручку от проданных товаров. Она же вызывает фабричные финансы:

    FUN_00488080 -> FUN_004F4B30(factory, market, ...)

Основные поля фабрики, используемые в этом проходе:

| Смещение | Поле |
|---:|---|
| +0x18 | тип фабрики |
| +0x1C | state |
| +0x20 | уровень |
| +0x150 | деньги фабрики, int64 |
| +0x158 | закупки сырья за прошлый день |
| +0x178 | подряд идущие дни убытка |
| +0x180 | субсидия |
| +0x184 | счётчик остановки |
| +0x188 | закрыта |

Деньги хранятся во внутренних единицах: 1 отображаемый фунт = 32768000 единиц.

## Статус

Подтверждено декомпилом и живыми хуками: порядок покупателей, условия обработки фабрик, вызов финансовых тиков, глобальные пулы. Осталось разобрать: формулы спроса по каждому товару, полная очередь мировой цены и правила распределения остатков между сферами.
