# Changelog

## 0.0.1 candidate - 2026-10-19

First ATCU release candidate, based on the accepted internal build 0.10.4.

- One shared package for vanilla and the active base mod, with native
  additive GUI definitions and a live unit catalogue.
- Local composition library, recruitment and unit pages/icons.
- Count controls: click 1, Alt-click 2, Ctrl-click 5.
- Conform previews changes, detaches extras without disbanding, and builds
  missing units through the engine queue.
- Session tracking marches and merges completed reinforcements.
- Conform recruitment and preview share safe land-reach eligibility.
- Native child activation fixes missing controls in DoD.
- Compact entry placement avoids crowded DoD unit folders.
- Verified extra-detachment handling and corrected land-flag interpretation.
- Short gameplay acceptance on vanilla, HPM 0.4.5, DoD Fan Fork and TGC
  2.5.2; TGC also accepted through V2DLL 5.82.
- New ATCU launcher label, files-only installation/removal guide, credits,
  issue-report instructions, content provenance and checksums.

Culture filters and continent selection are future work. No gameplay
code was changed when preparing this candidate.
