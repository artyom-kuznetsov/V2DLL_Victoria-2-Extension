# Candidate rights status

The project owner chose to leave the license undecided for this candidate.
No MIT, GPL or other project license is assigned by this package.

The owner's clarification about use of V2DLL-derived code is recorded in
`CREDITS.md`. Keep the source attribution markers. No additional request
to replace that code is part of this release preparation.

This candidate contains 28 DDS textures. Some are original drawn UI
elements, while others are crops, resizes or composites of installed game
or effective base-mod interface art. Generated filenames do not make those
textures original artwork. File-level generator references and categories
are listed in `PROVENANCE.json`. Exact original asset ancestry is not
available for every historical staged texture.

The previous staging did not record a redistribution permission for all
game-derived artwork. Public publication of this candidate therefore
still needs that status recorded, or an approved alternative for the
affected assets. The accepted appearance is retained for review; no art
replacement or visual redesign was silently introduced.

The package excludes the game executable, original Lua library, base mods,
V2DLL distribution, saved games, logs, Ghidra projects and decompiled dumps.
Native game sprite/font references are resolved by the installed game.
They are distinct from the 28 textures actually included here.
