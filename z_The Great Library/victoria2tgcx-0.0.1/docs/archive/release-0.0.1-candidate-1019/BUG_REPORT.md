# Reporting an ATCU problem

Use the [project issue tracker](https://github.com/azha2005/victoria2tgcx/issues).
Include:

- Candidate version and internal build, for example `0.0.1 / 0.10.4`.
- Windows version, game version, base-mod name/version and all ticked mods.
- Loader: included ATCU loader, or V2DLL and its version.
- What you clicked, the template composition, what happened and what you
  expected. Say whether you loaded a save during that session.
- For recruitment problems, the country, army location and relevant
  overseas provinces, shortages or access restrictions.
- A screenshot for interface defects, with resolution and UI scaling.
- `Logs/tgcx.log` from the game folder, preserved before launching again.
  For V2DLL also attach `Logs/v2dll.log` when relevant.

Logs can contain local file paths. Review attachments before posting.
Do not upload the game executable, original Lua library or full game/mod
installation. A checksum can identify a build without sharing its files.
