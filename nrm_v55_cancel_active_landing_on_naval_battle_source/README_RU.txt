NRM v53 — strict adjacent manual retreat

БАЗА
- EXE байт-в-байт равен подтверждённо рабочему v46/v52.
- DLL сохраняет research_optimum по неколониальным регионам и остальные рабочие NRM-модули.

ИЗМЕНЕНИЕ ОТНОСИТЕЛЬНО v52
- Больше НЕ обрезаем дальний retreat-route до первого шага.
- При ручном отступлении после vanilla retreat delay маршрут разрешается только если уже построенный Victoria маршрут содержит ровно один узел.
- Если маршрут содержит 2+ узла, приказ полностью отвергается: армия остаётся в бою.
- Если маршрут содержит ровно 1 узел, это непосредственная соседняя провинция по собственному movement graph Victoria; маршрут передаётся vanilla 0x5D1BB0 без модификации.
- Полное окружение по-прежнему проверяется vanilla chooser 0x5CF450: NULL => retreat order не применяется.

Таким образом:
  соседняя провинция -> retreat разрешён;
  несоседняя провинция -> retreat запрещён, без автоматического выбора первого шага;
  полный котёл -> retreat запрещён.

ТЕСТ
1. После 7 дней боя выбрать соседнюю допустимую провинцию: армия должна отступить туда.
2. После 7 дней боя выбрать провинцию через одну и дальше: приказ не должен сработать вообще.
3. Полный котёл: ручной retreat не должен работать.
4. Обычное движение вне боя: без изменений.
