### 4.11 `ENABLE_COUNTRY_GDP` — shared CALL `0x109F74`, HOOK `0x3125FC` (VA `0x7125FC`), on (added 5.19)

Shows the "GDP" of the country in the topbar rank panel: textbox `fe_country_gdp` (declared in `interface\topbar.gui`, the position is set by hand there). GDP = value of the goods produced in the country in the last **completed game month** − what the country's factories spent on input goods and maintenance (efficiency goods of the template) in that month. Display only; nothing in the game state is written.

* **Output (daily, in the shared daily CALL → `CountryGdpDaily`):** Σ over goods 0..63 of `saved_country_supply` of the country (`market+0x7D4`, per-country record `0x58` bytes, slot byte `+8+good`, `int64` vector at `+0x48`, 2¹⁵ fixed point — the same reader as `ConsCountryHolder` of goods_consumption) × current market price of the good (`ConsPriceOf`). It is what RGOs, factories and artisans produced.
* **Costs (daily):** for every open factory (`level +0x20 > 0`, closed byte `+0x188 == 0`) of the country — country `+0xE44` = list of nodes `{state*, ?, next@+8}` (the walk `FUN_00521FD0` uses), state `+0x60` = factory list, factory `+0x224` = next — the `int64` at factory `+0x158`. `FUN_00482FF0` (daily purchase of a factory) writes there the cost of everything it bought × `DAT_00F0ADE0` (= 1000, so the value is ×1000 as in the save's `last_spending`) and `FUN_004F4B30` compares it with the revenue `+0x160` (`+0x178` = unprofitable days). Real £ = value / 32768 / 1000. The factory's stockpile holds both the input goods and the template's `efficiency` goods (e.g. `raw_tea` and `fertilizer`), so this is "raw materials + maintenance" (not proven by a runtime trace — check the log, see below).
* **Month handling:** per-country accumulator (`g_gdpSlots`, 1024 slots keyed by the country pointer, same hashing as the minting cache), month number as in `MintingTimeNow` (`GdpTimeNow` adds the day-of-month and month length). On the first daily tick of a new month the accumulated sums become the "last month" values, but only if all days of that month were counted (a month entered by loading a save mid-month is **not** published — the box shows `-` until the first full month after the load). Accumulators are dropped when world time does not advance by exactly 24 h between ticks (load / new game). They are not saved: after a load the box stays `-` until the end of the next full month. A per-slot `lastHours` stops double counting if the hook is called twice in a day.
* **Display — HOOK `0x3125FC`** (6 bytes `8D 8D 94 FE FF FF` = `lea ecx,[ebp-0x16C]`, resume `0x312602` `E8`) in the topbar update `FUN_0070EC60`, right after the engine wrote `country_economic` (industry score of the selected country). There `EDI` = the country whose ranks are shown, `EBX` = topbar, `[ebx+0x20]` = its window (`vtable+0x3C` finds a textbox by name, box `+0xDC` = string, `+0xA0` = inner, `SetText` `0x65ECC0`, same as `SetBudgetBoxText`). `CountryGdpTopbarThunk`: one `pushad / push edi / push ebx / call CountryGdpTopbarUpdate / add esp,8 / popad` block, then the replayed `lea`, `jmp` to the resume. Text `%.0f` + byte `0xA4` (currency sign), `-` while no full month is known. A missing textbox is harmless (lookup returns null).
* **Log:** `LogDbg` only (needs `DEBUG_LOG=1`): per month for the player `выпуск − затраты = ВВП`, the first 12 daily lines (output, factory costs, number of factories and their revenue), textbox found/not found. Install line: `CountryGdp: установлен`.
* **Not counted:** wages, RGO/artisan inputs, goods bought by pops or the state. The value is gross production at the *current* prices at the moment of each daily sample.
* **Status:** static analysis only (not yet seen in game). Open points: whether `saved_country_supply` really is the whole day's production of the country, and whether factory `+0x158` includes the maintenance goods.


README entry:
#### 13a. ENABLE_COUNTRY_GDP
Shows the country's monthly "GDP" in the textbox `fe_country_gdp` of the topbar (you place it in `interface\topbar.gui`; it belongs to the ranking panel of the selected country): value of everything the country produced in the last completed month at current prices, minus what its factories spent on input goods and maintenance. Shows `-` until a full month has passed (also after loading a save).
